Windows 一鍵安裝（PowerShell）

                                
自動檢查 .NET 10 SDK、下載完整版並啟動瀏覽器：

                                下載 install-eccselection.ps1
                                
powershell -ExecutionPolicy Bypass -File .\install-eccselection.ps1

                            

                        

                        

                            

                                
macOS / Linux 一鍵安裝（Bash）

                                
自動檢查 .NET 10 SDK、下載完整版並啟動服務：

                                下載 install-eccselection.sh
                                
chmod +x install-eccselection.sh && ./install-eccselection.sh
